# Naveenkumar B — Full-Stack Python Developer Portfolio

A modern, high-performance developer portfolio showcasing full-stack Python engineering, REST APIs, database architecture, and responsive web applications.

🌐 **Live Demo:** [Portfolio Website](https://naveenkumarb.vercel.app) *(or your deployed URL)*

---

## 🚀 Tech Stack

- **Frontend:** React, TypeScript, Vite, Vanilla CSS, React Icons
- **Backend Specialization:** Python, FastAPI, Flask, REST APIs, SQLAlchemy, JWT Authentication, Supabase
- **Databases:** PostgreSQL, MongoDB, Supabase DB
- **Deployment & Tooling:** Vercel, Render, Git, GitHub Actions

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm / yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Naveenkumar1318/Portfolio-Website.git

# Navigate to frontend
cd Portfolio-Website/frontend

# Install dependencies
npm install

# Start development server
npm run dev
```
